Phase 6 — Production Quality Audit:

1. Host Header Scanner (Items 5+8) — False Positive Reduction
   - Tests 4 host values: evil.com, attacker.net, 127.0.0.1
   - Requires real reflection in body, redirect Location, or generated URL
   - Cache poisoning risk flagged as WARNING, not FAIL
   - PASS only when no reflection, redirect, or behavior change detected

2. Finding Deduplication (Item 1)
   - Finding._dedup_key: composite of module + first evidence description (80 chars)
   - Finding.merge(): increments occurrences, tracks affected URLs, merges unique evidence
   - ScanResult.add_finding(): merges with existing finding when dedup key matches
   - Finding.occurrences, affected_urls exposed in reports and to_dict()

3. Risk Score Rewrite (Items 2+3)
   - RiskCalculator class with transparent weighted formula
   - Factors: severity_weight x confidence_factor x verification_multiplier x occurrences_factor
   - Breakdown per finding with all intermediate values
   - Formula string included in output for report transparency
   - Warnings weighted at 50% of vulnerability severity

4. HTTP Request/Response Evidence (Item 4)
   - EvidenceType.REQUEST_RESPONSE enum value added
   - EvidenceBuilder.request_response() captures full request/response info
   - BaseScanner.capture_http_evidence() helper for all scanners
   - Raw data includes method, URL, headers, status, body snippet, body length, timing

5. Dynamic Confidence + Verification Levels (Items 6+7)
   - Finding.verification_status: verified/likely/possible/manual_review/unverified
   - Derived from highest evidence level in finding
   - _update_verification_status() called after every evidence addition
   - EXLPOITED+VERIFIED -> verified, CONFIRMED -> likely, LIKELY -> possible, POSSIBLE -> manual_review
   - Confidence bug fixed: error detection only triggers on EvidenceLevel.UNKNOWN evidence

6. Report Overhaul (Items 9-13)
   - Executive summary: contextual message based on highest severity
   - Attack surface summary: URLs crawled, modules scanned, HTTP requests, payloads, header/port tests
   - Risk score breakdown table: per-finding scores with verification, confidence, severity
   - Finding cards show verification status, occurrences, affected URLs
   - All emoji print statements replaced with ASCII-safe alternatives

7. Validation (Items 14-16)
   - 21 new validation checks for: deduplication, risk calculator, verification status,
     evidence types, to_dict completeness
   - All 120 checks pass (0 errors, 0 warnings)
   - Confidence calculation no longer triggers error path on non-error evidence containing "error"
