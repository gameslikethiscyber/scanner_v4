SEA Scanner Pro v5.0.0 - Windows Portable Build
================================================

Thank you for purchasing SEA Scanner Pro - a professional web application
security assessment tool.

QUICK START
-----------
1. Keep the "Sea Scanner Pro" folder intact (it contains the executable and
   its runtime support files in "_internal").
2. Double-click "SEA Scanner Pro.exe" to launch the desktop application.
3. Optional: right-click the exe -> Send to -> Desktop (create shortcut).

The app opens to the Overview screen. Use the left icon rail to navigate:
Overview / Scan / History / Settings / About.

RUN A SCAN
----------
1. Go to the Scanner page.
2. Enter a target URL you are authorised to test.
3. Choose a mode (Quick / Standard / Deep), thread count and timeout.
4. Click Start. A live progress bar and log panel appear.
5. When complete, the results summary opens with a risk meter, findings table
   and buttons to open the HTML report / open the PDF report.

This is a PORTABLE build - no installation is required. It runs from the
folder it is placed in. Reports are written to the "reports" folder (or the
folder set in Settings, next to the executable unless configured otherwise).

AUTHORISATION
-------------
Only test web applications you own or have explicit written permission to
assess. Unauthorised scanning is illegal in most jurisdictions.

TROUBLESHOOTING
---------------
- Smart-defender / antivirus may flag new unsigned executables. If so, select
  "Run anyway" / add an exclusion for the folder.
- If the app does not start, ensure your Windows is 64-bit and up to date.
- This build bundles the Python runtime and all core dependencies, so no
  separate Python installation is needed.

See the "Documentation" folder for the full guide, user guide and changelog.
